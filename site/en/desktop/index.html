The Raye desktop and apps

I tried everything described here in a Raye session, not just read the code. When I know of a flaw, or haven't finished trying something, it's written right below it.

The taskbar and Start

The taskbar is centered: Start, search, your pinned apps, then the clock on the right. With two screens each one gets its own taskbar and clock; the notification icons stay on the main screen, as in Windows 11. A minimized window keeps its button.

Start shows your pinned apps, then “All apps” as categories, a grid or a list. The apps carry their Windows names: Calculator, Paint, Photos, Media Player, Task Manager.

What is still missing

  • The search field and the Recommended section are not yet the Windows 11 ones.
  • Start and some menus open with a lag, and their animations are not yet the Windows 11 ones.

The shortcuts

These were tried one by one. The Win+X menu also opens with a right-click on Start, on the screen where the mouse is.

Arranging windows

Drag a window to the top of the screen: the layout bar shows up, and a pale area shows where the window will land. Let go and it snaps there. A 1920×1080 screen gets six layouts. On the desktop, Ctrl and the mouse wheel change the icon size.

Quick settings

A click on the right of the taskbar opens network, sound and, on a laptop, brightness. A click in the middle of a tile turns it on or off; its arrow opens a small page in the panel; a right-click leads to Settings. With a cable plugged in, the tile is called Ethernet.

File Explorer

Folders open in tabs, in the title bar, and the address bar also searches. A drive's Properties give the used and free space to the byte, with a Clean up button to make room.

There are no drive letters. In This PC the system disk is called Raye, and a Windows partition is called Windows. It's a choice: a letter says nothing about what's on the drive.

Task Manager

Ctrl+Shift+Esc opens it on Processes. It also has Performance, Startup apps, Users, Details and Services, with the services running on your PC.

What is still missing

  • The first start takes several seconds.
  • I have only seen the pages other than Processes on a virtual screen, not yet in a signed-in session.
  • “Run as administrator” doesn't start a program that has a window, and says nothing.
  • Four confirmation messages stay in English in a French session.
  • The Users page has no “Sign out” button.
  • Starting or stopping a service from the Services page has not been tried all the way yet.

Settings

One window, the list of categories on the left. That's where you pick the main screen, updates, drivers. When a Windows page has no counterpart in Raye, it says so and points to the handbook instead of staying empty.

What is still missing

  • In Installed apps, the “…” menu shows up see-through.
  • Several pages are not finished.

Control Panel and the Registry Editor

Win+R, control: Control Panel, by category. “Change the background” opens the right page of Settings.

Win+R, regedit: the Raye Registry Editor. Raye has no registry; the editor shows its real settings files as a tree, HKEY_CURRENT_USER for yours, HKEY_LOCAL_MACHINE for the system's. Writing to the system asks for your password, a copy is made before every write, and Edit, Undo puts the file back exactly as it was.

What is still missing

  • Ctrl+Z does nothing yet: use the Edit menu.
  • Once you've typed your password, the editor can write to the system for five minutes without asking again.
  • A settings file of a Raye app changed here is no longer replaced by that app's later updates.

Calendar

Create an event, close the window: between two reminders, no Calendar program is running. The reminder still arrives on time, with “Later” and “Dismiss”. The taskbar clock shows the day's events. Everything lives in one .ics file on your PC, which you can import and export.

What is still missing

  • You can't drag an event yet, change a single occurrence of a series, or show week numbers.
  • In English, dates are still in the French order, and reminder times on a 24-hour clock.

The Raye Store

Apps from Flathub and Raye's own, in one place. While an app installs you see the progress and can cancel; afterwards, Open and Uninstall. An app offered by two sources shows up once.

Lock and sign-in

The password field shows on the screen where the mouse is. Shut down and Restart work from the sign-in screen.

What is still missing

  • The account picture is not the same at sign-in and on the lock screen.

What doesn't have Raye's shape yet

The terminal, the screenshot tool and a few dialogs wear Raye's colors, but not its shape yet. There is no Notepad app: notepad opens the text editor.
