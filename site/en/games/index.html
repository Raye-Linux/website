Games: Steam, Proton and anti-cheat

Many Windows games run on Raye, some don't, and the reason is often an anti-cheat program. This page says what I know, and what I haven't been able to try yet: I haven't measured a single game on a real PC.

Steam

Steam is in the Raye Store. Raye installs it as a Raye package (APT) rather than Flatpak; if you already had it as Flatpak, Raye moves it once, with your games and settings, and tells you at sign-in. Steam sees your other drives: whatever is mounted under /media, /run/media and /mnt is offered when you add a library folder.

Game Mode turns on by itself while you play. Heroic, for other publishers' stores, is also in the Store.

What is still missing

  • On an NVIDIA card, Steam that opens and then shows nothing was reported. I fixed what I found, without being able to try it without an NVIDIA card: if it happens to you, tell me.

Proton, the Windows layer for games

Steam launches Windows games with Proton, its compatibility layer: that's what runs most of them. Raye is planning its own layer, Raye Proton, which you'll pick for a game in Steam. It's planned for 1.1, not for V1.

Anti-cheat

An anti-cheat is a program that watches the game and, sometimes, the system. What you need to know about Raye fits in three lines:

  • The ones that live in the Windows kernel, such as Valorant's Vanguard: they don't run on Raye, and I don't see how that would change.
  • Easy Anti-Cheat v2: it exists for Linux, but it checks the kernel and the state of Secure Boot, and its publisher, Epic, keeps a list of the keys it accepts. See below.
  • All the others: it depends on the game and its studio. ProtonDB says, game by game, what players have found.

Easy Anti-Cheat v2 and Raye's kernel

Raye's kernel is signed with a Raye key, which you enroll once in your PC. With Secure Boot on, Raye turns on what Easy Anti-Cheat v2 checks: kernel lockdown, kexec off and the IOMMU without passthrough. I checked those settings in the test machine, with Secure Boot and a virtual TPM chip, not yet on a real laptop.

What's left is Epic's list. I asked for Raye's keys to be added; the answer hasn't come. As long as Epic doesn't know them, Easy Anti-Cheat v2 refuses Raye's kernel. The day they're on it, it will be written here, not before.

What is still missing

  • Even with the key accepted, a game is only playable if its studio turned on Easy Anti-Cheat for Linux. Fortnite is the goal I set myself; I can't promise it to you.
  • PCs that already enrolled Raye's old key have to remove it: Easy Anti-Cheat wants every enrolled key to be known.

Graphics cards

Raye can fall back to a simpler display when the desktop doesn't start twice in a row, and picking “Safe graphics” on the stick helps when the screen stays black. Two problems reported by players are fixed in V1: older AMD cards (RX 400 and 500) that stayed in low resolution, and the black flicker of NVIDIA cards on a 144 Hz screen. I have neither of those cards: tell me if it works for you.

What is still missing

  • Low frames per second in Counter-Strike 2 were reported on a GTX 1650; I haven't measured it.
