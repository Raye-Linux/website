Before you install

An older PC: what was tried and what wasn't

Making Raye run on a PC from before 2012 is a goal of V1, not a result. Here is what I saw in a virtual machine that imitates an old PC, and what I didn't. No real old PC has received Raye yet.

What I saw

  • In a virtual machine in the old BIOS mode, with 2 GB of memory, a generic processor and a plain graphics card, the stick starts, and the installer opens in about twenty seconds.
  • The installer then says, on its first page, that the processor is on the older side: some programs and some games need a newer one. It doesn't stop the install.

What I'm trying for V1

  • Starting in BIOS mode, all the way through a full install.
  • Older 64-bit processors, such as the Core 2 Duo.
  • 2 to 4 GB of memory.
  • A graphics card without 3D acceleration.

What is still missing

  • A full install in BIOS mode wasn't redone with the current version: only the start up to the installer was seen.
  • No measurement on a real 2 or 4 GB PC. With under 4 GB, I don't know whether the desktop stays pleasant: 8 GB is still recommended.
  • Raye is 64-bit: a 32-bit PC, or a 64-bit processor too old for the base system, can't start it.

If you try it

If you have an older PC, try the trial session from the stick: it doesn't touch the disk. Then tell me, on Discord or at bonjour@rayelinux.com, the PC's model, what happened, and the raye-gpu.txt file if the screen stayed black or in low resolution. That's how this page will grow.
