Avant d'installer

Installer Raye, étape par étape

L'installateur pose ses questions en six étapes, que sa barre du haut affiche, et l'installation elle-même a pris 5 min 50 s sur la machine de test. Avant de commencer, sauvegardez vos fichiers. Je le dirais pour n'importe quel système ; je le dis deux fois pour un système aussi jeune.

Avant de commencer

Vérifiez que votre PC a ce qu'il faut (page Matériel). Une connexion Internet pendant l'installation est utile, pas obligatoire. Si vous gardez Windows, éteignez-le vraiment : désactivez le démarrage rapide et la veille prolongée. L'installateur vous prévient si Windows n'a pas été complètement arrêté.

Si Windows est chiffré, par BitLocker ou par le « Chiffrement de l'appareil » que beaucoup de PC vendus avec Windows 11 ont d'office, Raye ne peut pas réduire sa partition. Désactivez ce chiffrement dans Windows et attendez la fin du déchiffrement, en gardant votre clé de récupération BitLocker. L'installateur dit encore de « suspendre la protection » : ça ne suffit pas, la partition reste chiffrée.

La clé USB

  1. Téléchargez l'image

    Une fois l'image publiée, la page Télécharger donne le fichier, sa somme de contrôle et la façon de la vérifier.

  2. Écrivez-la sur la clé

    Avec Rufus, choisissez le mode image DD quand il le demande : le mode ISO donne une clé qui ne démarre pas. balenaEtcher marche aussi. Tout ce que la clé contient sera effacé.

  3. Démarrez sur la clé

    À l'allumage, souvent avec F12, F11, F8 ou Échap. Le menu de la clé, en anglais seulement, démarre par défaut sur « Try Raye Linux without installing » : une session d'essai qui ne touche pas au disque. L'icône « Install Raye Linux » est sur le bureau et en tête de Démarrer, et ouvre l'installateur en plein écran. Sur la ligne d'en dessous du menu, « Install Raye Linux » l'ouvre directement ; « Safe graphics » aide quand l'écran reste noir.

L'installateur, étape par étape

  1. Région

    Français ou anglais, le fuseau horaire, puis la disposition du clavier.

  2. Réseau

    La page suit votre connexion en direct : un câble branché apparaît tout de suite.

  3. Disque

    Quatre choix : effacer le disque, installer à côté de Windows en réduisant sa partition, utiliser l'espace libre, ou remplacer une partition. La case « Chiffrer le système Raye » est sur la même page : cochée, elle vous fait choisir un mot de passe du disque. Avec une puce TPM, vous n'aurez pas à le taper au démarrage.

  4. Compte

    Le nom du PC, puis votre nom et votre mot de passe. La page du compte Raye se passe avec « Utiliser plutôt un compte local ».

  5. Confidentialité

    La position et les statistiques d'usage, que vous pourrez changer plus tard dans les Paramètres.

  6. Installation

    « Prêt pour l'installation » dit tout ce qui va se passer, avec un bandeau rouge si quelque chose va être effacé.

Juste avant d'écrire, l'installateur relit le disque. Si quoi que ce soit a changé depuis votre choix, il s'arrête au lieu de continuer.

Garder Windows à côté

« Installer à côté de Windows » réduit la partition Windows pour faire de la place, et les deux systèmes partagent la partition de démarrage. Au démarrage, un menu propose Raye Linux et Windows pendant 10 secondes. Depuis Raye, « Redémarrer sous Windows », dans Démarrer, redémarre directement dans Windows, une fois.

Ce qui manque encore

  • Je l'ai prouvé sur une partition Windows de test, dans la machine de test : 50 Go réduits à 23 Go, et chaque fichier de Windows identique avant et après. Pas encore sur un vrai Windows réduit puis redémarré. Sauvegardez avant.
  • Le menu de démarrage affiche encore « Raye Linux GNU/Linux » au lieu de « Raye Linux ».
  • Sur un PC en mode BIOS d'autrefois, j'ai vu la clé démarrer jusqu'à l'installateur, pas l'installation complète : voir la page Vieux PC.

Ce que l'installateur ne fait pas

  • Pas de partitionnement à la main.
  • Seule une partition Windows (NTFS) non chiffrée peut être réduite.
  • Un disque qui porte déjà un autre Linux n'a que le choix « Effacer » : pas de troisième système.
  • Pas de PC 32 bits.

La clé de Raye et l'écran bleu

Le noyau de Raye est signé avec une clé de Raye. Pour que Secure Boot l'accepte, il faut inscrire cette clé une seule fois, et c'est le micrologiciel de votre PC qui le demande, sur un écran bleu au redémarrage, pas Raye. Avant de redémarrer, Raye vous montre un code à six chiffres à retenir.

  1. Appuyez sur une touche

    Vous avez environ 10 secondes à l'écran bleu pour appuyer sur une touche.

  2. Choisissez Enroll MOK

    Puis Continue, puis Yes.

  3. Tapez le code

    Le code à six chiffres que Raye vous a montré, puis Reboot.

Si vous manquez l'écran bleu, rien de grave : le PC démarre comme avant, avec le noyau du système de base, et Raye vous le redemandera. Sans Secure Boot, il n'y a pas d'écran bleu.

Ce qui manque encore

  • Je l'ai vu marcher dans la machine de test, avec Secure Boot et une puce TPM virtuelle : écran bleu manqué, puis écran bleu réussi, puis démarrage sur le noyau de Raye. Pas encore sur un vrai PC.
  • La clé USB d'essai garde le noyau signé d'origine : on n'inscrit rien pour essayer Raye.

Après

Au premier démarrage, si vous avez chiffré le disque, la puce TPM l'ouvre (sans puce, Raye demande le mot de passe du disque), puis vous tapez le mot de passe de votre compte. La clé de récupération s'affiche à la première connexion (voir Sécurité). Deux minutes plus tard, Raye prépare l'espace des programmes Windows en arrière-plan.

Ce qui manque encore

  • Sans chiffrement, le menu de démarrage reste affiché 5 secondes à chaque démarrage.

Revenir à Windows

Si vous avez gardé Windows à côté, il reste là : choisissez-le dans le menu de démarrage, ou « Redémarrer sous Windows » dans Démarrer. Retirer Raye du disque pour rendre toute la place à Windows n'a pas encore d'outil, et je n'ai pas encore essayé de marche à suivre : je ne vous en donne donc pas une.
