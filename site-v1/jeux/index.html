Les jeux : Steam, Proton et les anti-triche

Beaucoup de jeux Windows marchent sur Raye, certains non, et la raison est souvent un programme anti-triche. Cette page dit ce que je sais, et ce que je n'ai pas encore pu essayer : je n'ai mesuré aucun jeu sur un vrai PC.

Steam

Steam est dans le Raye Store. Raye l'installe comme un paquet de Raye (APT) plutôt qu'en Flatpak ; si vous l'aviez déjà en Flatpak, Raye le déplace une fois, avec vos jeux et vos réglages, et vous prévient à la connexion. Steam voit vos autres disques : ce qui est monté sous /media, /run/media et /mnt est proposé quand vous ajoutez un dossier de bibliothèque.

Le mode jeu s'allume tout seul pendant une partie. Heroic, pour les boutiques d'autres éditeurs, est aussi dans le Store.

Ce qui manque encore

  • Sur une carte NVIDIA, Steam qui s'ouvre puis n'affiche rien a été signalé. J'ai corrigé ce que j'ai trouvé, sans pouvoir l'essayer sans carte NVIDIA : si ça vous arrive, dites-le moi.

Proton, la couche Windows des jeux

Steam lance les jeux Windows avec Proton, sa couche de compatibilité : c'est elle qui fait tourner la plupart d'entre eux. Raye prévoit sa propre couche, Raye Proton, que vous choisirez pour un jeu dans Steam. Elle est prévue pour la 1.1, pas pour la V1.

Les anti-triche

Un anti-triche est un programme qui surveille le jeu et, parfois, le système. Ce qu'il faut savoir sur Raye tient en trois lignes :

  • Ceux qui vivent dans le noyau de Windows, comme Vanguard de Valorant : ils ne marchent pas sur Raye, et je ne vois pas comment cela changerait.
  • Easy Anti-Cheat v2 : il existe pour Linux, mais il vérifie le noyau et l'état de Secure Boot, et son éditeur, Epic, tient une liste des clés qu'il accepte. Voir plus bas.
  • Tous les autres : cela dépend du jeu et de son studio. ProtonDB dit, jeu par jeu, ce que les joueurs ont constaté.

Easy Anti-Cheat v2 et le noyau de Raye

Le noyau de Raye est signé avec une clé de Raye, que vous inscrivez une fois dans votre PC. Avec Secure Boot actif, Raye met en route ce qu'Easy Anti-Cheat v2 contrôle : le verrouillage du noyau, kexec coupé et l'IOMMU sans passthrough. Je les ai vérifiés dans la machine de test, avec Secure Boot et une puce TPM virtuelle, pas encore sur un vrai portable.

Reste la liste d'Epic. J'ai demandé qu'on y ajoute les clés de Raye ; la réponse n'est pas arrivée. Tant qu'Epic ne les connaît pas, Easy Anti-Cheat v2 refuse le noyau de Raye. Le jour où elles y sont, ce sera écrit ici, pas avant.

Ce qui manque encore

  • Même avec la clé acceptée, un jeu n'est jouable que si son studio a activé Easy Anti-Cheat pour Linux. Fortnite est le but que je me suis donné ; je ne peux pas vous le promettre.
  • Les PC qui ont déjà inscrit l'ancienne clé de Raye doivent la retirer : Easy Anti-Cheat veut que toutes les clés inscrites soient connues.

Les cartes graphiques

Raye sait revenir à un affichage plus simple quand le bureau ne démarre pas deux fois de suite, et choisir « Safe graphics » sur la clé aide quand l'écran reste noir. Deux problèmes signalés par des joueurs sont corrigés dans la V1 : les anciennes cartes AMD (RX 400 et 500) qui restaient en basse résolution, et le clignotement noir de cartes NVIDIA sur un écran à 144 Hz. Je n'ai ni l'une ni l'autre de ces cartes : dites-moi si ça marche chez vous.

Ce qui manque encore

  • Des images par seconde faibles dans Counter-Strike 2 ont été signalées sur une GTX 1650 ; je ne l'ai pas mesuré.
