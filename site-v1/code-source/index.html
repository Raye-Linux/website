Code source

Raye Linux est un logiciel libre. Tout son code est public, surtout sous licence GPL ; chaque dépôt indique la sienne. Il est sur GitHub et copié à trois autres endroits, pour rester disponible si l'un d'eux tombe.

Pour en avoir une copie, clonez depuis n'importe lequel des quatre, par exemple depuis notre serveur :

git clone https://dl.rayelinux.com/git/iso.git
