Raye Linux est un logiciel libre

Vous pouvez l'utiliser pour tout usage, l'étudier, le partager et le modifier, selon les licences de ses composants. Ces licences vous donnent ces libertés directement : vous n'avez rien à me demander.

Ce que la GPL vous permet, et vous demande

  • Vous pouvez exécuter le programme pour tout usage, privé ou commercial.
  • Vous pouvez l'étudier et le modifier, ce qui suppose d'avoir son code source.
  • Vous pouvez en partager des copies, modifiées ou non, gratuitement ou contre paiement.
  • Si vous partagez une copie, vous devez donner les mêmes libertés : la même licence et l'accès au code source correspondant.

Ces licences sont fournies sans garantie ; voir aussi les conditions d'utilisation.

Obtenir le code source

Pour obtenir le code source correspondant à la version de Raye que vous utilisez, écrivez à bonjour@rayelinux.com en donnant la version (elle est dans Paramètres, Système, Informations système). Je vous le fournis gratuitement par téléchargement, pendant au moins trois ans après la dernière diffusion de cette version. Le code des paquets du système de base est aussi publié par leurs auteurs.

Contributions

Un rapport de bogue, une idée ou un correctif que vous partagez reste à vous. Un correctif de code que vous m'envoyez pour qu'il entre dans Raye est accepté sous la licence du composant qu'il modifie.

Marques

« Raye Linux », « Raye » dans le nom de ses outils et l'œil de Raye sont les nôtres. Ils ne sont pas sous licence libre, pour que personne ne soit trompé sur ce qui vient de nous.

Ce que vous pouvez faire sans demander

  • Parler de Raye, en faire une critique, un tutoriel ou une vidéo, et montrer le logo pour l'illustrer.
  • Partager des copies non modifiées de l'image officielle, sous son nom.
  • Dire qu'un produit « fonctionne avec Raye Linux », si c'est vrai.

Ce qui demande mon accord

  • Partager une version modifiée sous le nom ou avec le logo de Raye : donnez-lui un autre nom et un autre logo, et vous pouvez dire qu'elle est « basée sur Raye Linux ».
  • Utiliser le nom ou le logo d'une façon qui laisse croire que je vous approuve, ou dans un nom de domaine, d'application ou de compte qui pourrait être confondu avec le projet.
