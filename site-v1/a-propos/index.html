Le projet

Qui fait Raye, et comment

Raye est fait par une seule personne, moi, au Québec. La première image de travail date du 30 octobre 2026.

Pourquoi

Je fais Raye pour quelqu'un qui connaît Windows 11 et qui veut changer de système sans réapprendre où sont les choses : la barre des tâches, Démarrer, les raccourcis, les Paramètres. Raye reprend cette disposition. Quand il s'en écarte, comme pour les lettres de lecteur, la page qui en parle dit pourquoi.

Comment c'est fait

Raye Linux est basé sur Ubuntu 26.04 LTS. Par-dessus, une quinzaine de dépôts de code sont ceux de Raye : le bureau et son thème, l'installateur, les Paramètres, le Store, Raye Update, l'Explorateur, le Gestionnaire des tâches et les autres applis, le noyau optionnel, le manuel et ce site.

Avant de publier une version, je l'installe de zéro sur la machine de test et je la mets à jour depuis la précédente ; depuis la 0.3, des captures d'écran sont prises toutes les 250 ms pendant le démarrage. Les paquets sont signés, et publiés sur deux copies vérifiées identiques fichier par fichier.

Licences et code source

Raye est fait surtout de logiciels libres ; certains micrologiciels de matériel, dont des cartes Wi-Fi ou graphiques ont besoin, ne le sont pas. Ce que j'écris pour Raye est sous licence GPL, version 3 ou ultérieure ; les pièces reprises d'ailleurs gardent leur licence (GPL, LGPL, MIT, BSD), et le manuel est sous CC BY-SA 4.0. Vous pouvez l'utiliser, le copier et le modifier selon ces licences.

Pour le code source d'un paquet de Raye, écrivez à bonjour@rayelinux.com en nommant le paquet et sa version : je vous l'envoie.
