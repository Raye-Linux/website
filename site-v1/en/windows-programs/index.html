Your Windows programs

Double-clicking an .exe file starts its installer, with nothing to set up first. What happens next depends on the program, and I don't have a list of programs tried to publish yet: it will be on this page.

A double-click

Double-click an .exe or .msi file: it opens. There is nothing to install first, and no question. The program's installer does its job and adds an entry to the Start menu, and the program then starts from there like a Raye app.

Every program gets its own space, so one that misbehaves doesn't break the others. That space is prepared in the background about two minutes after your first sign-in, and again after some updates: 26 seconds of work, using up to 3 GB of memory meanwhile, measured on the test machine.

When there is a Raye version

Some programs also exist for Raye, such as Discord or Steam. If you double-click their Windows installer, Raye offers you that version instead, made for Raye, which doesn't need the Windows layer.

What's missing, and why some programs don't start

Three pieces that Windows provides are not in Raye today. Most of the time, they are why a program doesn't start or looks wrong.

  • The Windows fonts (Tahoma, Segoe UI, Arial…). A program that asks for them gets another font, and a few windows end up badly laid out.
  • Direct3D to Vulkan translation, which gives games their speed. I haven't started a single game on this version, so I won't say yet what its absence costs.
  • .NET and the built-in web engine some programs expect. Those don't start.

What is still missing

  • The first program you open after installing takes a while.
  • Some installers show an old-style gray window.

Games

Games protected by an anti-cheat that installs itself in the Windows kernel, such as Valorant or Fortnite, don't run. It isn't a missing setting: their publisher has to allow Linux, and today they don't. Roblox doesn't start either: its anti-cheat refuses the Windows layer.

I haven't started any other game on a PC with a real graphics card, so I don't publish anything about them. Steam installs from the Raye Store, as a Raye version.

If a program doesn't work

Send me its name and version, what you did and what happened, at bonjour@rayelinux.com. The list of programs people report is what sets the order I fix things in.
