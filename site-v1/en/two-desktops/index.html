Two desktops: Raye's and Hyprland

The desktop all of this site talks about is Raye's. Hyprland is a second desktop, for people who want windows tiled by default and the keyboard first. Both are in the same install, and you move from one to the other without reinstalling.

Choosing

Raye's desktop keeps the Windows 11 layout: centered taskbar, Start, windows you drag and snap. It's the one you get after installing.

Hyprland is a desktop where windows line up side by side without you placing them, and where you do almost everything with the keyboard. It's for people who already know it, or want to learn it. Raye gives it its bar, its theme and its apps, and the installer offers Hyprland if you want it.

You choose in Settings > Personalization > Desktop environment, or on the sign-in screen, with the Desktop button at the bottom right. Switching reopens File Explorer and Settings on the new desktop.

Setting it up your way

Raye keeps its Hyprland configuration for itself and leaves you a file of your own: user.conf. Raye never overwrites it, even on an update. On the Desktop environment page, “Open my Hyprland settings” opens it in the editor, and raye-hyprland-config reloads, opens or goes back to Raye's settings from the terminal. To go back in one go, just remove your lines.

The guide

Raye's handbook has a chapter on Hyprland, “Hyprland on Raye”, opened by the “Hyprland guide” button on that same page. It says where the files are, what you can change and how: gaps, borders, corners, blur, animations, shortcuts, window rules, screens and scale, keyboard, startup, wallpaper, bar, lock and sleep. Every example is ready to copy, and all of them pass Hyprland's configuration check. It also says how to set Raye's apps (theme, icons, cursor, fonts) and what to do when one displays badly.

Other people's setups

Many people publish their Hyprland setup. Raye can install one with a single command, raye-hyprland-config dots install followed by the repository address. Before running anything, the command saves your settings, shows you the script and what it touches (sudo, package installs, deletions) and asks you to type yes. With no answer, nothing is changed. dots restore puts the previous state back, and Raye's desktop comes back by itself at the next sign-in if the installed setup crashes at start.

What is still missing

  • Many of these setups are written for other systems: their script may not run on Raye. In that case the backup protects you, but the install doesn't go through. I haven't yet tried a public repository from end to end.
  • Under Hyprland, Settings loads its 90 pages without error, but I haven't looked at all of them on screen. Night light and Multitasking say “Available on Raye's desktop”, because they only control that desktop. The mouse, the lock screen and the transparency effects are set in Hyprland's file rather than in Settings.
