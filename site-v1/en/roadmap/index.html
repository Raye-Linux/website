Roadmap

What's coming to Raye Linux, in order. Ideas from the community come first: a lot of what's below started as a message in #ideas on our Discord.

Share an idea on Discord Same list as #roadmap on the Discord.
  • Done
  • In progress
  • Planned

  1. Recently done

    Done
    • Done: New download (Nov 18) with all the latest fixes built in
    • Done: Join the team: apply in #join-the-team
    • Done: Automatic graphics fallback for older cards (more fixes for some AMD cards still coming)
    • Done: Simpler updates: no extra "Install now" step, apps reopen by themselves
    • Done: USB drives in This PC, opened in one click
    • Done: Apps open at their own size, minimize animation into the taskbar
    • Done: No more freeze when plugging in a second screen

  2. V1 Beta 1 · out November 19

    Done
    • Done: A much faster boot
    • Done: AMD Graphics Card panel (fans, power, profiles) and the NVIDIA Control Panel
    • Done: Better File Explorer and smoother mouse scrolling everywhere
    • Done: Performance options in Settings, with a transparency switch
    • Done: New Clock app: alarms, timer, stopwatch, world clocks
    • Done: Windows apps get their fonts, 32-bit games can use 4 GB, Store packages open
    • Done: Bigger Store, with Steam and Heroic built in
    • Done: Pinned web apps keep their real icon
    • Done: New installer: dual boot next to Windows or another Linux, resize partitions, better Wi-Fi page
    • Done: Cleaner, more reliable Raye Update
    • Done: "Try Raye" mode: use Raye from the USB stick without installing
    • Done: Store reviews and ratings
    • Done: Switch to Raye from another system and keep your files

  3. V1 Beta 2 (next big update)

    In progress
    • In progress: Choose KDE or Hyprland during installation
    • In progress: Windows 10 look option
    • In progress: A real Windows 10 Start menu
    • In progress: Windows-style window animations and snap previews
    • In progress: FL Studio, TikTok LIVE Studio and Affinity, "Optimized for Raye" once tested
    • In progress: Import your files from Windows
    • In progress: Install guide and keyboard support for Intel/AMD Chromebooks
    • In progress: Fix for older AMD cards (RX 400/500) stuck on a black screen or low resolution
    • In progress: Game performance: higher FPS and an advanced game mode
    • In progress: New Raye kernel tuned for gaming and smoothness
    • In progress: Lower RAM use at idle: 600–700 MB
    • In progress: Ready-made virtual machine images
    • In progress: Community Store requests: Quadra, rekordbox and Mixxx
    • In progress: 40+ popular Windows apps in the Store, each one tested
    • In progress: Windows apps install silently with a real progress bar, start to finish
    • In progress: Complete Windows bridge: share drivers, files and settings with Windows
    • In progress: Fix for the flicker on NVIDIA cards at 144 Hz
    • In progress: NVIDIA Control Panel opened from Settings
    • In progress: Clock: opens from the taskbar clock, and alarms wake the PC from sleep
    • In progress: Many more settings like Windows 11
    • In progress: Windows layer fully hidden: Raye file dialogs, no technical names in Task Manager
    • In progress: Bring your wallpaper, Wi-Fi networks, apps and browser data from your old system
    • In progress: Import your files from Windows right in Setup
    • In progress: Check for very old processors before installing
    • In progress: Update screen at startup shows its real percentage
    • In progress: Try Raye never touches the PC's own swap
    • In progress: Store settings, and Synaptic removed
    • In progress: Fix the maximize and snap glitch
    • In progress: Taskbar buttons clickable up to the screen edge
    • In progress: Laptops wake from sleep reliably
    • In progress: Automatic kernel security updates
    • In progress: Fix the Merge folders window in File Explorer

  4. V1 final

    Planned
    • Planned: Final polish and fixes from both betas
    • Planned: New website, with fresh screenshots of the real system
    • Planned: More languages
    • Planned: New ISO for everyone

  5. V2

    Planned
    • Planned: A second edition with rolling updates, kept in sync with the main one
    • Planned: Raye account: your settings follow you to every PC
    • Planned: ARM PCs
    • Planned: Spanish, German, Portuguese and Italian

  6. V3

    Planned
    • Planned: Phone apps on your PC
    • Planned: Local assistant and developer options
    • Planned: Every other language
