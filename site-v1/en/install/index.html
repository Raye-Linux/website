Before you install

Installing Raye, step by step

The installer asks its questions in six steps, shown in its top bar, and the install itself took 5 min 50 s on the test machine. Before you start, back up your files. I'd say it for any system; I say it twice for one this young.

Before you start

Check that your PC has what it takes (the Hardware page). An Internet connection while installing helps, it isn't required. If you're keeping Windows, shut it down properly: turn off fast startup and hibernation. The installer warns you if Windows wasn't fully shut down.

If Windows is encrypted, by BitLocker or by the “Device encryption” many PCs sold with Windows 11 have turned on, Raye can't shrink its partition. Turn that encryption off in Windows and wait for the decryption to finish, keeping your BitLocker recovery key. The installer still says to “suspend protection”: that isn't enough, the partition stays encrypted.

The USB stick

  1. Download the image

    Once the image is out, the Download page gives the file, its checksum and how to check it.

  2. Write it to the stick

    With Rufus, choose DD image mode when it asks: ISO mode gives a stick that doesn't start. balenaEtcher works too. Everything on the stick will be erased.

  3. Start from the stick

    At power on, often with F12, F11, F8 or Esc. Raye starts a trial session, and you start the installer from there.

The installer, step by step

  1. Region

    English or French, the time zone, then the keyboard layout.

  2. Network

    The page follows your connection live: a plugged-in cable shows up right away.

  3. Disk

    Four choices: erase the disk, install alongside Windows by shrinking its partition, use the free space, or replace a partition. The “Encrypt the Raye system” box is on the same page: ticked, it has you pick a disk password. With a TPM chip, you won't have to type it at startup.

  4. Account

    The PC's name, then your name and your password. The Raye account page can be skipped with “Use a local account instead”.

  5. Privacy

    Location and usage statistics, which you can change later in Settings.

  6. Install

    “Ready to install” says everything that will happen, with a red banner if anything is going to be erased.

Right before writing, the installer reads the disk again. If anything changed since you chose, it stops instead of carrying on.

Keeping Windows alongside

“Install alongside Windows” shrinks the Windows partition to make room, and both systems share the startup partition. At startup, a menu offers Raye Linux and Windows for 10 seconds. From Raye, “Restart to Windows” in Start restarts straight into Windows, once.

What is still missing

  • I proved it on a test Windows partition, in the test machine: 50 GB shrunk to 23 GB, and every Windows file identical before and after. Not yet on a real Windows shrunk and then restarted. Back up first.
  • The startup menu still shows “Raye Linux GNU/Linux” instead of “Raye Linux”.

What the installer doesn't do

  • No manual partitioning.
  • Only an unencrypted Windows (NTFS) partition can be shrunk.
  • A disk that already holds another Linux only gets “Erase”: no third system.
  • No PC that only starts in BIOS mode.

Afterwards

At first startup, if you encrypted the disk, the TPM chip opens it (without a chip, Raye asks for the disk password), then you type your account password. The recovery key shows at your first sign-in (see Security). Two minutes later, Raye prepares the space for Windows programs in the background.

What is still missing

  • Without encryption, the startup menu stays on screen for 5 seconds at every startup.

Going back to Windows

If you kept Windows alongside, it's still there: pick it in the startup menu, or “Restart to Windows” in Start. Removing Raye from the disk to give all the room back to Windows has no tool yet, and I haven't tried a way to do it: so I'm not giving you one.
