The Windows 11 desktop, on a system that isn't Windows.

Raye Linux is free and installs on an ordinary PC. Start sits in the middle of the taskbar, Win+E opens File Explorer, Ctrl+Shift+Esc opens Task Manager. Underneath, it isn't Windows, and this site tells you what that changes.

Version 1.0, in English and French.

What stays the same, what changes

You'll find

  • The centered taskbar, with Start, your pinned apps and the clock on every screen.
  • Win+X, Win+R and Ctrl+Shift+Esc, which open the same windows as on Windows.
  • File Explorer with its tabs, This PC and a drive's Properties.
  • A Control Panel and a Registry Editor, Raye's own.
  • An .exe file that starts with a double-click.

What is different

  • There is no “C:” drive. The disk is called Raye; a Windows partition, if there is one, is called Windows.
  • Updates that don't need a restart install while you work. The others wait until you choose “Update and restart”.
  • Apps come from the Raye Store rather than an .exe found on the web, though the .exe still works.
  • Some Windows programs don't run, and games protected by a kernel anti-cheat don't run at all.
  • When a program also exists for Raye, such as Discord or Steam, Raye offers you that version rather than the Windows one.

Three measurements, and their limits

I only publish what I measured, with the machine and the date. For now these figures come from a virtual machine without a graphics card, slower than a real PC: on a real PC they will be different, and they will be here.

Why I make Raye

I make Raye so that changing systems doesn't mean learning your computer all over again. The taskbar, Start and Settings should be where your hand already goes. When they aren't, tell me.

The first working image dates from October 30, 2026. Between it and this version came a Task Manager, a rebuilt File Explorer, updates that install without a restart, and a lot of things tried and thrown away. It's all on the Releases page.

If something doesn't work for you, write to me. That's how I decide what to fix first.
