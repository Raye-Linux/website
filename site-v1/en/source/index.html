Source code

Raye Linux is free software. All of its code is public, mostly under the GPL; each repository says which licence applies. It lives on GitHub and is copied to three other places, so it stays available if one of them goes down.

To get a copy, clone from any of the four, for example from our own server:

git clone https://dl.rayelinux.com/git/iso.git
