The project

Who makes Raye, and how

Raye is made by one person, me, in Quebec. The first working image dates from October 30, 2026.

Why

I make Raye for someone who knows Windows 11 and wants to change systems without learning again where things are: the taskbar, Start, the shortcuts, Settings. Raye keeps that layout. When it departs from it, as with drive letters, the page about it says why.

How it's made

Raye Linux is based on Ubuntu 26.04 LTS. On top of it, about fifteen code repositories are Raye's own: the desktop and its theme, the installer, Settings, the Store, Raye Update, File Explorer, Task Manager and the other apps, the optional kernel, the handbook and this website.

Before publishing a version, I install it from scratch on the test machine and update it from the previous one; since 0.3, screenshots are taken every 250 ms during startup. The packages are signed, and published on two copies checked to be identical file by file.

Licenses and source code

Raye is mostly made of free software; some hardware firmware, which Wi-Fi or graphics cards need, is not. What I write for Raye is under the GPL, version 3 or later; pieces taken from elsewhere keep their license (GPL, LGPL, MIT, BSD), and the handbook is under CC BY-SA 4.0. You may use, copy and change it under those licenses.

For the source code of a Raye package, write to bonjour@rayelinux.com naming the package and its version: I'll send it to you.
